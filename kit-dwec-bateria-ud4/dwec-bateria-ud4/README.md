# DWEC · Batería de ejercicios de la UD4 (Objetos y POO)

**Opcional** y **no cuenta para la nota**: es para practicar la UD4 antes del bloque A de la práctica.

1. `chmod +x bateria.sh` (solo la primera vez).
2. Lee la explicación de cada bloque en la web de DWEC: **UD4 · 4.1 Batería de ejercicios**.
3. Haz los ejercicios de `src/bloque1` … `src/bloque6`, en orden.
4. `./bateria.sh comprobar` (o `./bateria.sh comprobar 3`, solo un bloque).
5. Al terminar, contesta `respuestas.md`.

Necesitas **Docker** (el de la práctica 1). Todo va dentro de Docker: en tu ordenador no se instala nada más.
